# Fractionation-Plot-PFOA-pH
This plot is to show the computed percentages of PFOA and PFOA- anions equilibrium at different pH 
PFOA dissociation is described by:

𝐻𝐴⇌𝐻++𝐴−

The Henderson–Hasselbalch equation:
From that, the fraction of anion is

𝛼𝐴−=[𝐴−]/[𝐻𝐴]+[𝐴−]
=1/1+10^(𝑝𝐾𝑎−𝑝𝐻)

So percent PFOA anion is
%𝐴−=100⋅1/1+10^(3.8−𝑝𝐻)
